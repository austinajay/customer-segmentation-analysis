An interactive, executive-grade Customer Segmentation and RFM (Recency, Frequency, Monetary) analytics dashboard built on 805,549 e-commerce transactions. Identifies VIP customer concentration, churn vulnerabilities, international revenue drivers, and provides an interactive **What-If Revenue Uplift Simulator**.

Developed and maintained by **[Austin Ajay](https://github.com/austinajay)**.

## 🎯 Behavioral Segmentation Taxonomy & Playbooks

Customers were scored into quintiles (1 to 5) across **Recency (R)**, **Frequency (F)**, and **Monetary (M)** dimensions, grouping the customer base into 7 strategic cohorts:

```
+------------------+---------------------+-------------------+-------------------+---------------------------------------------------------------+
| Segment          | Value Tier          | Customers (%)     | Revenue (%)       | Recommended Marketing Playbook                                |
+------------------+---------------------+-------------------+-------------------+---------------------------------------------------------------+
| Champions        | High Value          | 1,292 (22.0%)     | ₹12.09M (68.1%)   | VIP concierge, private product previews, referral advocacy.   |
| Loyal Customers  | High Value          | 1,141 (19.4%)     | ₹2.64M (14.9%)    | Tiered loyalty progression, upselling premium categories.    |
| At Risk          | Low Value/At Risk   | 1,727 (29.4%)     | ₹2.02M (11.4%)    | Urgent win-back campaign, deep-discount comeback offers.      |
| New Customers    | Medium Value        | 441 (7.5%)        | ₹394k (2.2%)      | 30-day onboarding drip, first repeat purchase incentives.    |
| Need Attention   | Medium Value        | 512 (8.7%)        | ₹289k (1.6%)      | Personalized re-engagement series, satisfaction inquiry.      |
| About to Sleep   | Low Value/At Risk   | 496 (8.4%)        | ₹195k (1.1%)      | Seasonal catalog highlights, reactivate before total churn.   |
| Potential        | Medium Value        | 269 (4.6%)        | ₹111k (0.6%)      | Basket builder promotions (e.g., ₹20 off ₹100 spend).        |
+------------------+---------------------+-------------------+-------------------+---------------------------------------------------------------+
```

## 🚀 Key Features

- **Executive KPI Scorecards:** Real-time summary of revenue, customer volume, AOV, and churn risks.
- **Interactive Segment Visualizations:** Donut revenue distribution, headcount bar charts, and 5x5 RFM Matrix.
- **25-Month Historical Timeline:** Visualizes seasonal November/December sales spikes and demand cycles.
- **International Market Breakdown:** Revenue mapping across UK, Ireland, Netherlands, Germany, and France.
- **What-If Revenue Simulator:** Interactive sliders modeling real-time revenue gains from:
  1. *At-Risk Reactivation* (₹200k - ₹600k potential recovery)
  2. *Champions Frequency Expansion* (₹600k - ₹3.0M growth)
- **Live Customer Directory:** Search and filter all 5,878 customers by ID, country, segment, or tier with instant CSV export.
- **Multi-Platform Support:** Run via **Modern Web App (Vite/React)**, **Streamlit (Python)**, or inspect original **Power BI** dashboards.

## 💻 Local Setup & Execution

### 1. Web Dashboard (Vite + React)
```bash
# Navigate to project folder
cd customer-segmentation-analysis

# Install dependencies
npm install

# Start local development server
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

---

### 2. Python Streamlit Dashboard
```bash
# Install Python packages
py -m pip install -r requirements.txt

# Run Streamlit dashboard
streamlit run app.py
```

---

### 3. Re-run End-to-End Data Pipeline
```bash
py rfm_pipeline.py
```
This recalculates RFM quantiles from transactions and regenerates `data/customer_segments.csv`.

## 🌐 Deploy to Vercel

### Method A: One-Click GitHub Integration (Recommended)
1. Push this repository to your GitHub account (`austinajay`).
2. Log in to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import your `customer-segmentation-analysis` repository.
4. Framework Preset: **Vite** (auto-detected).
5. Click **"Deploy"**. Your live dashboard will be active in seconds!

### Method B: Deploy Directly via Vercel CLI
```bash
# Run Vercel CLI in the project directory
npx vercel
```
Follow the interactive CLI prompts to link to your Vercel account and deploy.
